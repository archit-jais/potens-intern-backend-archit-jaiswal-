# Potens Backend Q2 - Profile-to-Recommendation API

Initial Express.js backend setup for the Potens Q2 assignment.

## Tech Stack

- Express
- MySQL
- Sequelize
- dotenv
- cors
- helmet
- nodemon
- Jest
- Supertest

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

```bash
npm start
npm run dev
npm test
```

## Current Routes

- `GET /api/health` - basic API health check
